# Procedural Maze Art

Interactive browser demo: [maze-art.html](../../maze-art.html) (published at https://cavandonohoe.github.io/maze-art.html after merge).

A connected maze generated with randomized depth-first search, rendered as glowing outlines. Adjust columns, rows and seed; export a PNG. The Python version uses NumPy and Matplotlib: `python maze_art.py`.

Inspired by an installation photograph. This is **not** an implementation of the displayed optimization equation; that would require definitions of its variables and constraints.
